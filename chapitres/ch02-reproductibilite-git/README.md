# Chapitre 2 : Reproductibilité et développement professionnel

**Séance 1**, vendredi 13 novembre, matin (notebook 1) et **séance 2**, vendredi 27 novembre, matin (notebook 2 et tutoriel) · **Durée estimée : 30 + 60 minutes**

Organiser un projet, gérer ses dépendances (et savoir ce qu'un environnement virtuel ou `uv` apportera au deuxième quadrimestre), choisir entre notebook et script, entre Colab et sa propre machine, savoir où vivent les données et pourquoi jamais dans git. Puis, à la séance 2, Git et GitHub réduits à ce qu'il faut pour rendre un devoir : un tutoriel vous fait cloner votre dépôt du devoir 1 avec GitHub Desktop et y pousser votre premier commit.
